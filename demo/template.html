Multi-Agent Trajectory Prediction

The trained model reads 2 seconds of history for every agent in a nuScenes scene and predicts six possible 6-second futures for each pedestrian and cyclist, each with a probability. Everything below is computed by running the checkpoint on the validation scenes.

How a prediction is made

Encode history

A Transformer reads each agent's 5 past steps (x, y, vx, vy) at 2 Hz, the nuScenes keyframe rate.

Model interactions

A graph attention network lets each agent attend to its neighbours.

Add map context

Cross-attention over lane polylines. This copy of the dataset has no map files, so the map input carries no lane information here.

Propose goals and latents

A goal head scores endpoints; a CVAE samples latent variables to cover different behaviours.

Decode and rank

A GRU decodes 20 candidate paths of 12 steps (0.5 s each); the top 6 by ranking score are returned.
